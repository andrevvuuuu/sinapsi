# Sinapsi Fase 1 — Base dell'app — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Mac desktop app that opens with the approved home layout, reads the Obsidian vault (read-only), stores its own data, and can call Gemini (via `agy`) and Claude (via `claude -p`) through one tested bridge.

**Architecture:** Electron with three parts: `main` (Node: files, vault, AI processes, data store), `preload` (typed safe API), `renderer` (React UI). Data is append-only JSONL plus a small settings file in the app data folder. All AI calls go through one bridge module with queue, schema validation, cache and usage log.

**Tech Stack:** electron-vite (react-ts template), Electron, React 18, TypeScript strict, zod, chokidar, gray-matter, vitest, @testing-library/react, Playwright (`_electron`), electron-builder.

**Spec:** `docs/design.md` (sections 2, 3, 4 point 1, 5, 6).

## Global Constraints

- macOS only; target arm64; app name `Sinapsi`; bundle id `it.andreaantonelli.sinapsi`.
- The app never writes inside the vault. Vault default path: `~/Obsidian Vault`.
- App data folder: `~/Library/Application Support/Sinapsi/` (override with env `SINAPSI_DATA` for tests).
- Vault override for tests: env `SINAPSI_VAULT`.
- AI: no API keys. Gemini through `agy -p … --output-format json`; Claude through `claude -p … --output-format json`. stdin closed on every call.
- Default task routing: `extract`, `note`, `variants`, `notebook` → `agy` model `gemini-3.8-flash-high`; `teach`, `grade` → `claude`.
- Excluded vault folders: `.obsidian`, `.antigravity`, `.trash`, `Prompts`.
- UI language Italian. Themes `lavagna` (dark: bg `#0f100d`, ink `#ece9df`, accent `#ef7a42`) and `trattato` (light: bg `#f3eee4`, ink `#221e19`, accent `#a83d22`); fonts Instrument Serif, Geist, Geist Mono, Caveat; contrast WCAG AA; targets ≥ 44 px; respect `prefers-reduced-motion`.
- `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true` for the renderer.

## Review Focus

1. **AI CLI asks to log in** (agy/claude print a browser-login prompt and wait) → call must end within the timeout with `AuthRequiredError`, never hang. Test in Task 3.
2. **AI CLI hangs or is slow** → killed after `timeoutMs` (default 180 000) with `AiTimeoutError`; the queue keeps working for the next call. Test in Task 3.
3. **iCloud placeholder files** in the vault (listed but unreadable, ENOENT/EAGAIN on read) → note listed with `available: false`, scan continues. Test in Task 4.
4. **Wikilink variants** `[[Nota|alias]]`, `[[Nota#Titolo]]`, `[[Nota#^blocco]]`, `[[Nota#^b|alias]]`, links to missing notes → resolved target title, heading/block kept, unresolved flagged. Test in Task 4.
5. **Vault path missing or wrong** (folder deleted, never set) → home shows a clear message with a "Scegli la cartella del vault" button; no crash. Test in Task 6.

### Task 3: AI bridge (agy + claude)

**Files:**

**Interfaces:**
- Consumes: `appendJsonl`, `dataDir`, `loadSettings` (Task 2).
- Produces:
  - `type Engine = 'agy'|'claude'`; `type Task = keyof Settings['engines']`.
  - `buildArgs(engine: Engine, prompt: string, model?: string): { cmd: string; args: string[] }` — agy: `['-p', prompt, '--output-format','json','--print-timeout','170s', ...(model?['--model',model]:[])]`; claude: `['-p', prompt, '--output-format','json', ...(model?['--model',model]:[])]`.
  - `parseOutput(engine: Engine, stdout: string): { text: string; inputTokens: number; outputTokens: number }` — agy JSON `{status:'SUCCESS', response, usage:{input_tokens,output_tokens}}`; claude JSON `{is_error:false, result, usage:{input_tokens,output_tokens}}`; any other shape → `AiOutputError`.
  - `extractJson(text: string): unknown` — accepts raw JSON or the first fenced ```json block or the outermost `{…}`/`[…]`.
  - Errors: `AuthRequiredError`, `AiTimeoutError`, `AiOutputError`, `AiSchemaError`, `EngineMissingError` (command not found).
  - `createBridge(deps: { spawn: SpawnFn; now?: () => number; cacheDir: string; usageFile: string }): Bridge` where `Bridge.ask<T>(req: { task: Task; prompt: string; schema?: z.ZodType<T>; cache?: boolean; timeoutMs?: number }): Promise<{ data: T | string; fromCache: boolean; engine: Engine }>` and `Bridge.status(): Record<Engine, 'idle'|'busy'|'auth'|'missing'|'error'>`.
  - `SpawnFn = (cmd: string, args: string[], opts: { timeoutMs: number }) => Promise<{ stdout: string; stderr: string; code: number | null; timedOut: boolean }>`; real implementation `nodeSpawn` in `engines.ts` (child_process.spawn, `stdio: ['ignore','pipe','pipe']`, cwd = home, SIGTERM then SIGKILL after 2 s on timeout, PATH extended with `~/.local/bin` and `/opt/homebrew/bin`).

Behavior pinned by tests: one call at a time per engine (FIFO), different engines run in parallel; auth detection = stdout or stderr matches `/authentication page|log ?in|login required|not authenticated/i` → `AuthRequiredError` and status `auth`; when `schema` is given and validation fails, one retry with the prompt + `\n\nLa risposta precedente non era valida: <zod message>. Rispondi solo con JSON valido.`, then `AiSchemaError`; cache key = sha256 of `engine|model|prompt|schemaName` stored as `<key>.json` in `cacheDir`; every non-cached call appends `{ts, task, engine, model, inputTokens, outputTokens, ms, ok}` to `usageFile`.
