# Sinapsi Fase 4b — Memoria e Ripasso — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every concept of the graph gets a memory (FSRS); the Ripasso session asks the concepts that are fading, each time in a new form (pre-generated variants of many exercise types, chosen by Andrea), with confidence, reasoning, an AI-proposed grade he can change, and misconception detection; the graph shows memory states and lenses.

**Architecture:** Reviews are append-only events (`reviews.jsonl`); each concept's FSRS card is rebuilt by replaying its reviews with `ts-fsrs` (no stored mutable state). Question variants are generated by Gemini (task `variants`) in one call per note for the concepts that lack them, validated leniently like the nota viva, stored in `variants.jsonl`. Open answers are graded by Claude (task `grade`, one-shot `ask` with a schema); every other type is graded deterministically in the renderer. The session queue is built in main (due concepts by lowest retrievability, subjects interleaved).

**Tech Stack:** existing + `ts-fsrs@5.4.2` (MIT, stable since 2026-09-01).

**Spec:** `docs/design.md` §2 row "Ripasso" ("FSRS per concetto; domande sempre in forma nuova (4–5 varianti pre-generate); fiducia + ragionamento; voto proposto dall'AI e modificabile; errori sicuri → misconcezione → mini-Apprendimento"), row "Esercizi" (12 types), approved prototypes `docs/prototipi/ripasso-v1.html` (session) and `docs/prototipi/esercizi-v1.html` (catalogue: Richiamo / Distinzione / Composizione), user: "posso poter scegliere" (he chooses the exercise types); `docs/prototipi/grafo-v2.html` lenses and memory colours.

## Global Constraints

- Grades are FSRS ratings 1 Di nuovo, 2 Difficile, 3 Bene, 4 Facile; the button shows the interval FSRS would give (`10 min`, `1 giorno`, `4 giorni`…).
- Proposed grade: correct + confidence ≥ 70 → 3; correct + confidence < 50 → 2; correct otherwise → 3; partially correct (open, AI verdict `partial`) → 2; wrong or "Non lo so" → 1. Wrong with confidence ≥ 70 → misconception: shown in the reveal and the summary, with "Studia questo concetto" (starts a learning session on the concept name).
- Memory state from retrievability R now: never reviewed → `mai visto`; R ≥ 0.85 → `la sai` (good); 0.6 ≤ R < 0.85 → `incerto` (warn); R < 0.6 → `debole` (bad). Due = FSRS `due` ≤ now.
- Exercise types in this phase (10 of the 12 in the spec): `open` (Richiamo), `mc` (Distinzione), `truefalse` (vero/falso + perché), `order` (Riordina i passi), `fill` (Completa, `{{a|*b|c}}` like the nota viva), `match` (Abbina), `counterexample` (Scegli il controesempio), `estimate` (Stima, numeric with tolerance), `spoterror` (Trova l'errore), `graph` (Sul grafico: a phase-3 `Figure` plus a target expression that must be ≈ 0 at the chosen parameter). Deferred: "Spiegalo a voce" (needs audio), "Etichetta lo schema", "Collega i concetti".
- Variants: 4–5 per concept, at least 3 different types, never two of the same type in a row for one concept; a variant already asked is not repeated until all have been used.
- Session size: up to 20 due concepts (setting `reviewSessionSize`, default 12), most-forgotten first, then interleaved so consecutive items come from different notes when possible.
- UI copy Italian; 44 px targets; confidence slider step 10 default 50; keyboard: ⌘↩ submits an open answer.

## Review Focus

1. **A concept reviewed many times, reviews out of order in the file, or two reviews at the same millisecond** → replay sorts by time and is deterministic; never throws. Test in Task 1.
2. **Gemini variants with a wrong `correct` index, a fill without `*`, an order list with duplicates, a graph variant whose expressions do not compile** → that variant dropped, others kept; a concept with no valid variant falls back to a generic open recall question built from its statement. Test in Task 2.
3. **Claude grading fails or times out** → the reveal still shows the reference answer, proposes grade 2 with "Non sono riuscito a correggere: valuta tu", and the session continues. Test in Task 3.
4. **No concept due** → the Ripasso home says so and offers "Ripassa comunque i più deboli" (lowest R); a graph with no concepts → explains that concepts come from studying notes. Test in Task 5.
5. **App closed mid-session** → reviews already graded are kept (each grade is appended immediately); the next session starts fresh. Test in Task 3.
